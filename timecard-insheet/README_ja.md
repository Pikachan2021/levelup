# シート内ボタン式 ワンタップ打刻

**スプレッドシートの中にボタンを置き**、クリックすると「Emeli T＆C」シートの
**今日の日付の行・該当列に現在時刻が入力**される方式です。別ページは開きません。

- 操作はシート上で完結（ボタンをクリックするだけ）
- ログイン不要（編集権限のある人がクリック）
- 押し間違いは「⏱ 打刻」メニューの「直前の打刻を取り消す」で戻せる

> ⚠️ **本番シートはまだ変更しません。** まずは作成済みの
> 【テスト用コピー】で動作確認してください。

---

## しくみ
シートに「図形（ボタン）」を挿入し、各ボタンに下記の関数を 1 つずつ割り当てます。
クリックすると Apps Script が走り、今日の行の該当セルに `HH:mm` を記入します。

| 割り当てる関数 | スタッフ / 項目 | 書き込む列 |
|---|---|---|
| `punch_emeli_packing`  | えーめり / パッキング     | B |
| `punch_emeli_company`  | えーめり / かんぱにワーク | C |
| `punch_markus_packing` | マルクス / パッキング     | D |
| `punch_markus_company` | マルクス / かんぱにワーク | E |
| `punch_tuomas_packing` | Tuomas / パッキング      | F |
| `punch_tuomas_company` | Tuomas / かんぱにワーク  | G |
| `punch_antti_packing`  | Antti / パッキング       | H |
| `punch_antti_company`  | Antti / かんぱにワーク   | I |

> 列がズレている／項目を増やす場合は `Code.gs` の `CONFIG.STAFF` の数字（列番号）を直すだけ。

## セットアップ手順

### 1. コードを貼り付ける
テスト用コピーを開き、**拡張機能 → Apps Script**。
既定の `コード.gs` を全削除し、本フォルダの **`Code.gs`** を貼り付けて保存。

### 2. （任意）対象シート名を確認
`CONFIG.SHEET_NAME` を実際のタブ名（例 `Emeli T＆C`）に合わせる。

### 3. シートにボタンを挿入する（8 個）
1. 「Emeli T＆C」シートを開く。
2. メニュー **挿入 → 図形描画**。
3. 図形（角丸四角など）を描き、中に文字を入れる（例：`えーめり パッキング`）。
4. **保存して終了** → シートにボタンが貼られる。
5. 貼られたボタンを選択 → 右上の **⋮（縦三点）→ スクリプトを割り当て**。
6. 割り当て名に上表の関数名（例 `punch_emeli_packing`）を**そのまま入力**して OK。
7. 同様に 8 個分のボタンを作成・割り当て（スタッフ×項目）。

> 1 個作って割り当てたら、ボタンをコピペして文字と割り当て関数名を変えると速いです。

### 4. 初回クリックで承認する
最初にボタンを押すと「承認が必要」と出るので、自分のアカウントで許可。
以降はクリックするだけで打刻されます（画面右下にトーストで結果表示）。

---

## 使い方（スタッフ向け）
1. スプレッドシートを開く。
2. 自分の項目のボタン（例 `えーめり パッキング`）を**クリック**。
3. 今日の行の該当セルに現在時刻が入り、右下に「✓ えーめり パッキング 14:30」と表示。
4. 押し間違えたら、メニュー **⏱ 打刻 → 直前の打刻を取り消す**。

---

## 注意・調整
- **「今日の日付の行が見つかりません」** → `SHEET_NAME` / `DATE_COL` を確認。日付列に今日の「日」が必要。
- **時刻がずれる** → `CONFIG.TIME_ZONE` を確認。
- **既定は追記**（`08:00, 12:30`）。1 日 1 回だけにしたいなら `CONFIG.ON_EXISTING = 'overwrite'`。
- 図形ボタンは編集権限のある人がクリックする前提です（閲覧のみの人は押せません）。

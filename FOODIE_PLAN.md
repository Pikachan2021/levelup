# Foodie-tilausjärjestelmä — suunnitelma

## Tilausten kategoriat

Tilaukset jaetaan 3 kategoriaan:

- **a) Chuumon** — normaalitilaukset (asiakastilaukset)
- **b) Cafe** — kahvilatarvikkeet (Komorebi)
- **c) CW (Company Work)** — esim. Kouvolan lakritsi ym. tuotteet, joita ei saa Kesprosta

## Prosessi

- Hikaru rakentaa järjestelmän / automaation
- Riku selittää työn sisällön Hikarulle
- Anun rooli = vain tarkistus (kakunin dake)
- Tavoite: ei manuaalista työtä (manual shigoto nashi)

## Lisätietoja

- Foodie-tilaus tehdään alkuviikolla (ma–ti)
- Shopify + Linnworks avoimet tilaukset tarkistetaan:
  - sunnuntaisin
  - alkuviikolla (uudet tilaukset edellisen tarkistuksen jälkeen)
- Riku voi hakea tilausdataa Notekunin kautta
